    Model. Steady state each hour, solved so the heat exchanger plus the TEGs reject exactly the heat the IT load puts into the liquid loop. Tube side: Gnielinski (turbulent) and Sieder–Tate (laminar) with Petukhov friction. Shell side: Kern's method. Bundle diameter from standard tube-count constants. TEG: 1-D module model with Peltier and Joule terms, contact resistance, substrates, interface material and heat-sink resistance in series, solved for junction temperatures. Thermoelectric properties are held at ~50 °C values. Material presets for Type I, Type II and the commercial baseline follow Nozariasbmarz et al., iScience 23, 101340 (2020). Liquid-cooling classes follow ASHRAE TC 9.9. Costs, battery data and tariff values are editable estimates, not quotes. The default grid factor is the proposal's national figure; Ontario's grid is much cleaner, so lower it for an Ontario site.
